# Eman Shoaib — Personal Web Development Portfolio

A beginner-friendly portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — styling, Flexbox/Grid, hover effects and responsive design
- `script.js` — mobile navigation and demo contact-form interaction
- `documents/` — the two earlier HTML assignment PDFs linked from the Projects section

## Run locally
Open `index.html` in a browser. In VS Code, Live Server is optional but useful.

## Important note about the contact form
The form is a front-end demonstration. It validates required fields and displays a confirmation message, but it does not send or store messages.

## Publish with GitHub Pages
1. Upload the files and `documents` folder to the `main` branch of the repository.
2. In the repository, open Settings → Pages.
3. Under Build and deployment, choose “Deploy from a branch”.
4. Choose branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. Use the URL shown in Settings → Pages.
